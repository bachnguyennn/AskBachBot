AZURE AND CLOUD DATA ENGINEERING EXPERIENCE

This document covers Bach Nguyen's cloud and Azure experience: volunteer data engineering with Statistics Without Borders, an Azure hackathon challenge, and related cloud and data-engineering tools.


DATA ENGINEER (VOLUNTEER) — STATISTICS WITHOUT BORDERS, PROJECT #279

Role: Data Engineer (Volunteer)
Organization: Statistics Without Borders (SWB), Project #279
Client: IPÊ (Instituto de Pesquisas Ecológicas, the Institute for Ecological Research), a biodiversity and conservation organization in Brazil
Location: Remote
Dates: February 2024
Tools used: Microsoft Azure (cloud storage and data pipelines)

What the project was: IPÊ stored large-scale environmental and biodiversity datasets across Dropbox and OneDrive, which made the data hard to organize, query, and scale. Statistics Without Borders, a volunteer organization of the American Statistical Association, put together a cross-disciplinary team of statisticians, engineers, and scientists to help.

What Bach did:
- Reviewed IPÊ's existing data storage and management practices and identified the challenges of keeping large environmental datasets in consumer file-sharing tools.
- Researched alternative data-engineering solutions by benchmarking best practices from similar organizations and industries.
- Designed sample Azure data pipelines to organize the large-scale biodiversity datasets for the team.
- Audited cloud storage practices and designed a data-organization strategy to improve query performance and reduce storage costs.
- Worked with statisticians and scientists to align the data solution with research needs and support data-driven decisions for biodiversity conservation.


HACK HIVE HACKATHON — AZURE CHALLENGE

Bach took part in the Azure Challenge at the Hack Hive hackathon. The team designed a system using Microsoft Azure cloud services and presented the idea and its cloud architecture maps to Microsoft Azure directors and specialists.
